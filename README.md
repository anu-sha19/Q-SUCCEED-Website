# Q-SUCCEED-CNY Website

The **Q-SUCCEED-CNY** website is the official online platform for the **Quantum and Semiconductor Upskilling for Career Change in Central New York (Q-SUCCEED-CNY)** program, an **NSF-funded workforce development initiative** led by Syracuse University.

The website provides prospective participants with information about the program, including workshops, eligibility requirements, industry partnerships, application details, and contact information. It serves as a central hub for individuals interested in exploring careers in the rapidly growing semiconductor, photonics, and quantum technology industries.

Designed with accessibility and responsiveness in mind, the website streamlines the application process, highlights community and industry collaborations, and promotes educational opportunities that prepare adult learners and career changers for high-demand technical careers in Central New York.

Website link: https://q-succeed-cny.org/
